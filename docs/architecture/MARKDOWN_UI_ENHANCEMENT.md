### 2. SETTINGS.md - Provider Configuration

Add new section after Kernel Configuration:

```markdown
## 🔌 LLM Provider Configuration

**Current Provider:** `anthropic` ✅

| Setting | Value | Options |
|---------|-------|---------|
| `provider` | anthropic | anthropic, openai, openrouter |

**To change:**
```
SET provider=openai
SET pro_model=gpt-4-turbo
SET low_model=gpt-3.5-turbo
```

---

## ⚡ Execution Mode

**Current Mode:** `simulation` ⚠️

| Mode | Description |
|------|-------------|
| `simulation` | Dry-run mode - no real API calls, no file writes |
| `live_fire` | Real execution - API calls, file writes enabled |

**To enable Live Fire:**
```
SET mode=live_fire
```

**⚠️ WARNING:** Live Fire mode makes real changes. Use with caution.
```

## Implementation Plan

### Phase 1: Config Structure
1. Create `vibe_core/config.py` - Central configuration management
2. Define config schema for:
   - LLM provider settings
   - Execution mode (simulation/live_fire)
   - Model selections

### Phase 2: Settings Sync Enhancement
1. Update `settings_sync.py` to parse new SET commands
2. Update `doc_renderer.py` to render new sections
3. Implement config persistence (YAML or JSON)

### Phase 3: Preserved Fields
1. Implement field preservation in renderers
2. Extract user content before re-render
3. Re-inject user content after render
